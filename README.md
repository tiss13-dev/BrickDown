#BrickDown

Casse-briques style Street/Urban développé en HTML, CSS et JavaScript.
##Description

BrickDown est un jeu de casse-briques au design sombre et urbain.
Casse toutes les briques avant de perdre tes 3 vies!

##Fonctionnalités

Explosion de particules à chaque brique cassées
Sons générés directement en JavaScript
Power-ups cachés dans les briques
Plusieures niveaux de difficulté progressive

##Power-ups

Raquette large - ta raquette s'aggrandit
Balle de feu - traverse les briques en explosant
+Vie -  une vie supplémentaire

##Comment jouer

Glisse le doigt sur l'écran (mobile)
ou utilise les boutons <> en bas

##Technologies

HTML5
VSS3
JavaScript (Canvas, Web Audio AP)
